# Changelog

All major changes in the Mystic Framework will be documented here. You'll find every module's version releases and changes
chronologically. For module-specific changelogs, refer to that module's own documentation, as this page compiles all changes.

This page follows the standard changelog structure:
```
[MODULE_NAME] [VERSION] - [DATE]

[TAG]
- Item 1
- Item 2
- ...
```

**Tags and their meanings:**
- `ADDED`: A new feature has been added.
- `CHANGED`: An existing feature has been modified.
- `DEPRECATED`: A feature has been marked as deprecated and will be removed.
- `REMOVED`: A feature has been removed.
- `FIXED`: A bug has been fixed.
- `SECURITY`: A security issue has been addressed.

For more information on how to write a changelog, refer to [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
