# Design Philosophy

This section outlines the core principles and design choices that guide the development of our framework. By understanding these philosophies,
developers can better appreciate the rationale behind various features and make informed decisions when building applications.

## Core Principles

MFW works on five basic principles that guide its design and development:
- Zero-overhead
- Performance
- Elegance
- Opt-in
- Modern

### Zero Overhead

Just as the core philosophy of C++ is "you don't pay for what you don't use", MFW follows the same principle. If a feature is not used,
it should not introduce any overhead or complexity into the application. This approach allows developers to build high-performance applications
without being burdened by unnecessary abstractions or dependencies.

### Performance

MFW is designed with performance in mind, ensuring that applications built with the framework can run efficiently and effectively. The
framework leverages modern C++ features and optimizations to provide developers with the tools they need to create high-performance applications.

### Elegance

MFW takes readability and maintainability as first-class concerns. The framework's API is designed to be intuitive and expressive, allowing
developers to write clean and elegant code. By prioritizing elegance, MFW helps developers create applications that are not only functional
but also easy to understand and maintain.

> "Elegance is not a dispensable luxury but a quality that decides between success and failure." - Edsger W. Dijkstra

### Opt-in

Every module, every feature, and every dependency in MFW is opt-in. This means that developers have full control over which components they
want to include in their applications. By allowing developers to choose only the features they need, MFW minimizes bloat and ensures that
applications remain lightweight and efficient.

### Modern

MFW embraces modern C++ standards and practices, ensuring that developers can take advantage of the latest language features and improvements.
By staying up-to-date with the evolving C++ landscape, MFW provides developers with a framework that is both current and forward-looking.
