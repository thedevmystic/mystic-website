# Roadmap

This roadmap outlines the future plans and upcoming features of the framework. It serves as a guide for developers and contributors
to understand the direction of the project and what to expect in the coming releases.

## Upcoming Features

The following features are planned for future releases:
- CMake module for project maintenance, health checks, and dependency management.
- Install tool for easy installation and setup of the framework on host system.

## Finished Features

The following features have been completed and are available:
- Mystic Framework website and documentation.
