# API Reference - MysticIncludeModules

`MysticIncludeModules` module provides `mystic_include_modules()` function it is used to process all the modules in the `modules` directory of the project. It is responsible for including all the modules in the project and making them available for use.

## Prerequisites

Before using the `MysticIncludeModules` module, ensure that you have the following prerequisites:
- Called `mystic_project()` from `MysticProject` module.
- Called `mystic_setup_options()` from `MysticSetupOptions` module.

## Function Signature

```cmake
mystic_include_modules([<ROOT_DIR>])
```

Here, `<ROOT_DIR>` is an optional argument that specifies the modules directory of the project. If not provided, it defaults to `${CMAKE_CURRENT_SOURCE_DIR}/modules`.

## Basic Usage

To use the `MysticIncludeModules` module, you need to include it in your `CMakeLists.txt` file and call the `mystic_include_modules()` function. Here's an example of how to do this:

```cmake
# ... CMakeLists.txt content ...

include(MysticIncludeModules)
mystic_include_modules()

# ... rest of your CMakeLists.txt content ...
```

## With Custom Modules Directory

To use a custom modules directory, you can provide the path to the `mystic_include_modules()` function. Here's an example:

```cmake
# ... CMakeLists.txt content ...

include(MysticIncludeModules)
mystic_include_modules(${CMAKE_CURRENT_SOURCE_DIR}/custom_modules)

# ... rest of your CMakeLists.txt content ...
```

## Technical Notes

- This function recursively processes all the modules in the specified modules directory and includes them in the project. It ensures that all the modules are available for use in the project.
- To view the implementation of `mystic_include_modules()` function, you can check the [GitHub repository](https://github.com/mystic-framework/cmake/blob/main/modules/MysticIncludeModules.cmake).
