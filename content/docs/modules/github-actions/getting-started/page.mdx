# Getting Started with GitHub Actions

This guide will help you get started with GitHub Actions module and help you automating your software development workflows.

## Available Actions

- Pre-Commit Checks
- C++ Compatibility
- Python Compatibility & Linting
- SonarQubeCloud Integration

You can use the actions in your workflows as follows:

```yaml
name: "CI/CD Workflow Name"

on:
  push:
    branches:
      - main
  pull_request:
    branches:
      - main
  workflow_dispatch:

jobs:
  workflow-job:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repository
        uses: actions/checkout@v7

      - name: Step Name
        uses: mystic-framework/github-actions/<action>@v1
```
